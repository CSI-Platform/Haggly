# Haggly Prompt Playbooks

These files are concise source material for the v2 Haggly agent harness.

They are not canned scripts. The API prompt assembler selects the relevant playbooks, combines them with structured negotiation context, and lets the hosted model decide whether to ask questions, recommend a move, or draft wording.

Original research and older car negotiation notes remain in `research/` and `scripts/` as reference material.
