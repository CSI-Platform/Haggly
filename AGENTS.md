## Project Context

This is the private canonical repo for Haggly v2. The target product is a green AI negotiation chat app with a dashboard.

Do not treat the current live static site as the product direction. The live site is useful only as a source for deploy notes, SEO/content, and selected assets.

## Development

- Install dependencies with `npm install`.
- Run locally with `npm run dev`.
- Verify changes with `npm run build`.
- Do not commit secrets or `.env` files.
- Keep generated build output out of git.
